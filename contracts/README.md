# Contracts

The single source of truth for the HTTP interface shared by `dmoney_back` and
`dmoney_front`.

## Files

| File | Role | Author |
| ---- | ---- | ------ |
| `openapi.json` | Machine truth — full OpenAPI 3.1 spec | Generated by back-end CI |
| `API_CONTRACT.md` | Curated semantics (owner-scoping, errors, business meaning) | Humans |
| `CHANGELOG.md` | Contract versions and breaking changes | Humans |

`openapi.json` is **not** committed until the back-end's contract-sync pipeline
first publishes it. Until then, `API_CONTRACT.md` is the only contract artifact.

## How the contract flows

```
[dmoney_back] push to trunk
  ├─ CI: build + test
  └─ repository-dispatch → [dmoney_platform]
        ├─ contract-sync.yml: run back's OpenAPI export test (H2, no server)
        │                     → contracts/openapi.json
        └─ contract-gate.yml (on PR): oasdiff breaking-change check

[dmoney_front] reads contracts/ as a read-only reference (via opencode.json)
```

### Producer — `dmoney_back`

- CI dispatches a `contract-sync` event to this repo on every trunk push.
- A change to any endpoint/model must be reflected in the generated spec in the
  same change set.

### Hub — `dmoney_platform` (this repo)

- `contract-sync` regenerates the spec by running the back-end's
  `OpenApiExportTest` (in-memory H2, no server) and commits it (via PR on
  `trunk`).
- `contract-gate` runs `oasdiff` against the previously released spec. A
  breaking change fails the check and must be recorded in `CHANGELOG.md`.

### Consumer — `dmoney_front`

- Reads `contracts/openapi.json` and `API_CONTRACT.md` as the reference source
  of truth (wired through `dmoney_front/opencode.json`).
- There is no code generation or drift gate; the contract is documentation for
  the front-end and its agents.

## Versioning

Contract versions are recorded in `CHANGELOG.md`. Follow semver at the contract
level:

- **major** — breaking change (removed/renamed endpoint or field, tightened type).
- **minor** — additive, backward-compatible (new endpoint or optional field).
- **patch** — docs/semantics only, no wire change.
